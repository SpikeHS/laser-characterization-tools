# Changelog

## 0.1.0 — 2026-09-18

First public release of selected laboratory analysis tools. Extracted the
interactive spectral viewer from its embedded measurement dataset; added
synthetic demo generation, explicit-unit filenames, input checks and JSON export.
Renamed the spectral classification to a spacing-rule result.

Consolidated LIV calculations into a tested package and CLI, replacing the
minimum-WPE threshold heuristic with a documented, user-selected linear fit.
Added source hashes, explicit units, non-overwriting outputs and CW scope.
